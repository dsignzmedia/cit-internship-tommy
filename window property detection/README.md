# 🪟 Prompt-Based Window Feature Detection using Roboflow API

This project uses a pre-trained Roboflow model to detect window design attributes such as handles, grids, glass presence, and other features. It works by sending images to the Roboflow API and visualizing detected features using bounding boxes.

---

## 📂 Project Overview

- Upload a window image (e.g., `wimg1.jpg`)
- Use the Roboflow hosted model to predict window components
- Visualize predictions with labels and confidence scores
